# Sicilijos kelionė

Interaktyvus Tomo ir Elenos kelionės planas: 2026 m. spalio 24 – lapkričio 3 d.

Puslapyje yra visas dienų planas, išskleidžiami paaiškinimai, Sicilijos ir Europos žemėlapiai, nakvynių bei vakarienių nuorodos.

## Atidaryti

`index.html` veikia tiesiogiai naršyklėje. Žemėlapio duomenys ir D3 biblioteka įdėti į failą; išoriniam ryšiui naudojamos tik paspaustos nuorodos.

## GitHub Pages

Repository Settings → Pages → Deploy from a branch → main → / (root).

## Duomenys

Nakvynių kainos yra paieškos biudžeto tikslai, ne patvirtinti pasiūlymai. Konkrečios datos autobusų vietos ir Etnos sąlygos turi būti patikrintos prieš užsakant. Šaltiniai pateikti puslapio išskleidžiamoje skiltyje.
